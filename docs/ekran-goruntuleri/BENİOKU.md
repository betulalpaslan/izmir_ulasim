# Ekran görüntüleri

Buraya üç PNG bırakın, sonra README.md'nin başındaki yorum bloğunu açın:

| Dosya | İçerik |
|-------|--------|
| `rotalar.png` | Rota sonuç kartları — etiketler, süre, ücret dökümü |
| `harita.png`  | Harita üzerinde çizili çok modlu güzergâh |
| `bisim.png`   | BİSİM hizmet alanı ve bonus bölge katmanı |

Emülatörden görüntü almak için: `adb exec-out screencap -p > rotalar.png`
